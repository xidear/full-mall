# ADR-0010: 法律文档版本化与接受证据

- 状态：Accepted
- 日期：2026-10-18

## 背景

用户协议、隐私政策、退换货政策等具有法律效力，必须能证明“用户在某个时间接受了某个版本、某个语言的某份文本”。不同市场法律主体和语言版本不同。

## 决策

- 文档（Document）与版本（Version）分离；版本发布后不可修改，任何变更生成新版本。
- 每个版本按 locale/市场生成本地化文本；法律文档必须人工审校。
- 接受记录（Acceptance）保存：
  - 用户/游客标识
  - 文档版本 ID
  - locale、市场
  - 接受时间、IP、User-Agent
  - 方式（clickwrap / e-sign）
  - 内容哈希
  - 订单/会话 ID
- 实质性条款变更触发重新同意；非实质性变更提示。
- 已发布文本渲染为 PDF，保存源文件、PDF、哈希和渲染时间。
- 顾客协议使用 clickwrap；供应商合同可独立部署 Documenso 做电子签名。
- 合规按市场配置：PIPL、PDPO、PDPA、台湾地区个人资料保护相关法规。

## 后果

- 需要运营/法务/翻译协作流程和发布审批。
- 订单、注册、结账必须记录接受证据。
- 文档变更不能直接改数据库文本，必须走版本发布。

## 替代方案

- 直接把条款写在页面里：无法证明用户接受了哪个版本，不可接受。
