# 分销绑定矩阵（客服与普通推广共用）

> 用户口径（2026-10-19）。客服在聊天里发商品等同于"以客服为推广人"的分享，
> **没有任何特殊规则**，与普通客户分销完全一致。

## 1. 两个维度

- **绑定方式**：`ONCE`（一次性）/ `PERMANENT`（永久）
- **绑定时机**：`VISIT`（访问商品即绑定）/ `CART`（下单才绑定）/ `REGISTER`（注册时绑定）

## 2. 矩阵（客服分享商品时）

| 绑定方式 | 时机 | 客户**无**上级 | 客户**已有**上级 |
|---|---|---|---|
| ONCE | VISIT | 访问即绑定；**首单**分佣，之后不分佣 | **仍分佣并覆盖**原上级（后到冲掉先前） |
| ONCE | CART | 首单时绑定并分佣，之后不分佣 | 同上，覆盖 |
| PERMANENT | VISIT | 访问即永久绑定，**以后所有订单**都分佣 | **不建立**新关系（保留原上级） |
| PERMANENT | CART | 仅访问不绑定；下单才永久绑定 | 不覆盖 |

## 3. 必须写进代码的判定顺序

```
1. 读配置：mode(ONCE|PERMANENT) + timing(VISIT|CART|REGISTER)
2. 触发点：
   VISIT  → 商品详情被访问（带推广人标识）
   CART   → 下单校验通过后
3. 判定：
   if 已有上级 == null            → 建立绑定
   else if mode == ONCE           → 覆盖绑定（写新上级，旧关系置为 SUPERSEDED）
   else (PERMANENT)               → 保持不变
4. 分佣计算时按"下单时刻的有效绑定"取推广人
```

## 4. 边界与坑

| 情况 | 处理 |
|---|---|
| 客户自己点自己的推广链接 | 拒绝绑定（自购不分佣） |
| 客服给客户发商品但客户直接搜进来 | 不绑定（必须带推广人标识访问） |
| 同一客户短时间内被多人分享 | 按上面的覆盖规则，最后生效者得佣金 |
| 一次性绑定后客户退款 | 佣金按售后 DEFER 规则回冲（见 A6/D11） |
| 员工佣金渠道 | 默认 `PAYROLL`（走工资），不计入可提现余额；客服是否同此**待确认** |

## 5. 已确认（2026-10-19）

1. **客服佣金走 `PAYROLL`**（工资/绩效），不计入可提现余额。
2. **已结算的佣金永不追回**。覆盖只影响之后的订单——上一单是上一单的业务，
   换人结算不影响历史；系统不允许任何"追回历史佣金"的逻辑。

## 6. 实现修正记录

原实现的 ONCE/PERMANENT 语义**与业务相反**（ONCE 当成"保持第一个"、PERMANENT 当成"后到覆盖"），
2026-10-19 已按业务口径修正，并补测试锁定：

| 模式 | 正确行为 |
|---|---|
| ONCE | 后到覆盖先前；只停用关系，**不动已结算佣金** |
| PERMANENT | 已有上级则保留原关系 |
