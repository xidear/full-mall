# 后台信息架构（IA）

> 目标：管理员按"我要做什么"找得到，不按"系统里有什么表"找。
> 原则：一级按**任务域**分组（≤7 组），二级≤8 项；跨域高频项放"工作台"。

## 一级分组

| 组 | 包含页面 | 谁常用 |
|---|---|---|
| **工作台** | 经营总览、待办（订单/售后/临期/审批） | 全员首屏 |
| **商品** | 商品列表、SKU 规格矩阵、规格改价、品牌管理、分类、评价管理 | 商品运营 |
| **交易** | 订单、售后、退款、发货/履约、砍价活动 | 订单客服 |
| **库存** | 库存批次、临期商品、盘点、调拨、收货、在途 | 仓管 |
| **营销** | 促销活动、优惠券、会员/积分、分销、提现审核 | 营销 |
| **财务** | 成本查询、对账（供应商退货）、导出中心、结算 | 财务 |
| **系统** | 用户与角色、通知、第三方服务、许可证、审计、系统设置 | 管理员 |

## 归位规则（把现有散落页面收进来）

| 现有页面 | 应归入 |
|---|---|
| 品牌管理、SKU 规格矩阵、规格改价 | 商品 |
| 成本查询、导出中心 | 财务 |
| 临期商品 | 库存 |
| 许可证 | 系统 |
| 操作审计（含实体快照） | 系统 |
| 通知管理 | 系统 |
| 第三方服务（新建，ADR-005） | 系统 |

## 交叉入口（避免来回找）

- 工作台每个待办卡片 → 直接跳对应列表并**带筛选条件**（如"待发货 12"→ 订单页已筛待发货）；
- 商品页每行 → 快捷入口：改价（进规格改价并预填商品）、成本（进成本查询）、库存（进批次）；
- 临期商品页 → 行内"去促销"跳到新建活动并预选该 SKU。

## 布局规范

| 位置 | 内容 |
|---|---|
| 左侧固定导航 | 7 个一级组（可折叠），组内二级；当前组高亮 |
| 顶部 | 面包屑（组 / 页面）+ 全局搜索 + 账号 |
| 内容区 | 标题 → 说明/告警 → 筛选 → 表格 → 操作；**筛选永远在表格上方**，不放右侧抽屉 |
| 危险操作 | 独立区 + 二次确认，不与常用按钮并排 |

## 验收

- 任一业务动作（改价、看临期、查成本、导出、改第三方配置）**≤2 次点击**可达；
- 一级组≤7、二级≤8；
- 每个页面都有帮助条目（已有门禁 `scripts/check-help-coverage.py`）。
