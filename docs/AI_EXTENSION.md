# AI 能力规划与开源/私有边界

> 状态：规划（本仓库 = 开源版）。本文档定义**接口与边界**，不含模型、不含训练代码、不含数据。

## 1. 开源版与私有版的边界

| 能力 | 开源版（本仓库） | 私有版（另行维护） |
|---|---|---|
| 行为数据采集 | ✅ 埋点与事件表（浏览、收藏、加购、下单、搜索词） | — |
| 推荐/画像**接口** | ✅ 只定义接口与降级实现（无模型时返回空） | ✅ 提供真实模型 |
| 模型训练 | ❌ 不提供 | ✅ 私有 |
| 提示词/权重/语料 | ❌ 不提供 | ✅ 私有 |
| AI 客服答案生成 | ✅ 接口 + mock 实现 | ✅ 真实 LLM |
| 图片生成（主图/场景图） | ✅ 接口 + 占位图实现 | ✅ 真实生成 |
| 角色形象生成（虚拟导购） | ✅ 接口 | ✅ 真实生成 |

**硬原则**：开源版任何一个 AI 端点，在没有配置私有服务时都必须**明确返回"未启用"**，
不得返回伪造的推荐结果（会污染运营判断）。

## 2. 接口清单（开源版提供）

| 端点 | 用途 | 无模型时行为 |
|---|---|---|
| `GET /api/v1/recommendations?scene=home\|product\|cart` | 推荐商品 | 返回空列表 + `enabled=false` |
| `POST /api/v1/ai/chat` | 客服问答 | 503 `AI_NOT_CONFIGURED` |
| `POST /api/v1/ai/describe` | 商品文案生成 | 503 |
| `POST /api/v1/ai/image` | 图片生成 | 503 |

配置项（后台）：`ai.provider`（空/`private`）、`ai.endpoint`、`ai.key`（脱敏存储）。

## 3. 数据采集（开源版负责）

已有/待补事件：

| 事件 | 现状 |
|---|---|
| 浏览（`member_browse_history`） | ✅ |

## 4. AI 全面参与的设想（私有版路线）

| 领域 | AI 角色 | 输入 | 输出 |
|---|---|---|---|
| 运营分析 | 分析师 | 订单/库存/退款数据 | 异常预警、补货建议、活动效果归因 |
| 商品 | 文案与图像 | 商品属性 | 标题、卖点、主图/场景图 |
| 客服 | 一线应答 | 会话 + 订单 | 回答、转人工判断 |
| 推荐 | 推荐引擎 | 行为序列 | 首页/详情/购物车推荐 |
| 定价 | 策略建议 | 成本、竞品、库存 | 折扣建议（**由人确认后生效**） |
| 风控 | 审核 | 订单/退款模式 | 异常标记（不自动封禁） |
| 内容 | 生成 | 主题配置 | 首页文案、活动页文案 |
| 角色 | 虚拟导购 | 品牌设定 | 形象图、对话人格 |

**红线**：AI 不直接改价格、不直接退款、不直接封号——只给建议，人确认。

## 5. 与现有模块的接入点

| 模块 | 接入方式 |
|---|---|
| `catalog` | 商品描述/图片生成 |
| `support` | 会话应答建议（**客服仍可编辑后发送**） |
| `promotion` | 活动方案建议 |
| `distribution` | 佣金异常检测（建议，不自动调整） |
