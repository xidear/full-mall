## 2. 执行顺序（关键路径）

```
A1 → A2/A3 → B1 → B2/B3 → B5 → B6/B7/B8
                 ↘ C1 → C2/C3 → C4
      A1 → D1 → D3 → D4 → D5/D6
      A1 → E1 → E2/E3 → E5 → E6
      A3 → F1 → F2 → F3/F4 ；F5 → F6
      G4 → G5 ；G1/G3 可并行
```

理由：方法级授权与审计是供应商/客服/ERP 共用的前置；支付依赖凭证与回调幂等；促销依赖会员主体。

## 3. 每轮 DoD（强制）

1. `mvn -B test` 全绿（0 跳过；无 Docker 时集成测试自动用嵌入式 PostgreSQL）。
2. `mvn -Pprod package` 与 `-Pdemo package` 通过。
3. 新迁移在 `MigrationSmokeTest`（真实 PostgreSQL）跑通。
4. 新接口进 `OpenApiContractTest` 必测清单。
5. 负向测试：越权/未授权/重放/限流至少各一条。
6. 文档同步：`PROJECT_MEMORY.md`（迁移/陷阱）、`IMPLEMENTATION_STATUS.md`（本轮记录与实测数字）。
7. 推送只推 Gitea；公开分叉不得含 `.env` 与凭据。
