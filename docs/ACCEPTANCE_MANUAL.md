# 人工验收清单（8 项补齐全）

> 环境：admin `http://127.0.0.1:41281`，账号 `admin / Admin@123456`；API `http://127.0.0.1:41280`。
> 每项 30 秒内可验完；「通过标准」写的是**你能亲眼看到的结果**。

## 准备（30 秒）

```bash
cd /data/full-mall
bash scripts/dev-stack.sh status      # API 41280 / admin 41281 / storefront 41285 都应 UP
```

---

## ① 列表状态内联切换（AGENTS §13.1）

1. 打开「市场配置」→ 找到 HK 行 → 点状态开关。
2. 期望：弹出确认框；确认后该行变为「已停用」，**不需要打开编辑弹窗**。
3. 打开「员工与权限」→ 对自己那行：开关应为禁用（防自锁）。
4. 打开「第三方服务 → 优惠券」列表（营销 → 优惠券）→ 状态列是开关，启用=开始发放、停用=停止发放。

通过标准：三处都能在列表内切换；失败时状态保持原样并弹错误。

## ② 枚举/裸码检查（CI）

```bash
cd /data/full-mall && make contract-check
```

通过标准：输出包含
`兜底检查通过（93 处已登记）` 与 `枚举检查通过（11 处已登记）`，且退出码 0。

## ③ 通知状态机（已读 ≠ 已修复）

1. 打开「通知中心」。
2. 表头应有「处理状态」列；新通知显示「待处理」。
3. 点「认领」→ 该行变「处理中」；点「标记已修复」→ 变「已修复」。

通过标准：状态按 待处理 → 处理中 → 已修复 变化，且刷新页面后仍是新状态。

## ④ 通知跳转由后端下发

1. 在「通知中心」找一条事件为 `STOCK_LOW`（库存告警）的通知。
2. 点「查看」。

通过标准：跳到「库存与批次」页；不再是前端自己猜的映射（后端 `link` 字段为 `/inventory`）。

## ⑤ AI 未命中问题清单

1. 打开「AI 客服」。
2. 在提问框输入一句含辱骂词的话（例：`你这个傻逼机器人`）→ 点提问。
3. 期望：回答区显示「问题包含不当内容，已转人工处理」。
4. 页面下方「未命中问题（补知识库用）」表格出现该问题原文。

通过标准：拒答 + 清单里能看到这条问题。

## ⑥ 业务编码一键生成

1. 打开「商品 → 品牌管理」→ 点「新建」。
2. 点编码输入框旁的「生成」。

通过标准：编码框自动填入形如 `BRAND-4KDVH-1983` 的值；重复点不会给出已存在的编码。

## ⑦ 存储一致性校验脚本

```bash
cd /data/full-mall
python3 scripts/migrate-storage.py --verify --dir /data/full-mall/server/data/assets
```

通过标准：输出「库内 local 记录 N 条；缺失 0；空文件 0」。
（当前可能有 1 条缺失，是早期目录配错时写进容器文件系统的那张图——这条正是脚本要发现的问题。）

## ⑧ AI 问答（含真实模型开关）

1. 打开「AI 客服」→ 提问「运费怎么算？」。
2. 当前环境期望：返回 503 `AI_EMBEDDING_NOT_CONFIGURED`，页面显示"未配置向量模型"。
3. 配置一个 `protocol=openai-embedding` 供应商 + `openai-chat` 供应商，并向 `knowledge_chunk` 灌 FAQ 后重试。

通过标准：
- 未配置 → 明确的 503 与可操作提示（不是"没有答案"）；
- 配置后 → 回答带「引用来源」（sourceId + 相关度 + 命中片段），模型不能篡改引用。
