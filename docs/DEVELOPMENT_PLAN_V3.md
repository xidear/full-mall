## 1.6 CRMEB 概念对照结论（2026-10-19）

见 `docs/CRMEB_DESIGN_STUDY.md`。三条最该补的：

1. **`commission_ledger` 佣金账本**：现有 5% 直接生成、支付即得，退款后对不上；应改为
   「订单完成 → 冻结 → 可提现」状态机，并支持按比例回冲。**金融正确性优先。**
2. **`cart` / `member_address`**：服务端购物车与地址簿是商城常规能力，当前缺失。
3. **小程序三件套**：`openid/unionid` 登录、手机号授权（加密存储）、订阅消息模板与发送日志。

另外补：评价、收藏、足迹、提现单、物流轨迹；规格模板与品牌。

不照搬：金额最小单位（已有）、DIY 页面 JSON（用 `theme_config`）、表名字段名、多商户 marketplace。

## 2. 执行顺序（关键路径）

```
A1 → A2/A3 → B1 → B2/B3 → B5 → B6/B7/B8
                 ↘ C1 → C2/C3 → C4
      A1 → D1 → D3 → D4 → D5/D6
```
