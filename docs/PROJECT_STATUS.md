- **订单**：下单、库存预占、支付、履约、自提核销（集成 + E2E）
- **支付**：Mock 渠道完整（支付/退款/事件）；真实渠道 ⬜
- **会员**：手机 OTP 登录（限流+失败计次+会话哈希）、资料、登出、等级折扣、积分赚取/抵扣/回退、收藏、足迹、消息中心
- **促销**：满减/满折引擎（取最优、SKU/类目/品牌范围、渠道隔离）、试算 API、后台构建器（创建/列表/编辑/启停）、POS 收银接入、**后台可视化界面（已 E2E 验证）**
- **优惠券**：模板（含适用范围）、领券（原子防超发）、可用性校验、**结算按命中金额抵扣**（互斥/叠加可切换）、退款退券、**后台管理页（已 E2E 验证）**
- **分销**：佣金生成（支付后）、定时解冻、退款回冲、提现（申请/审核/打款）
- **售后**：申请 → 审核 → 收货 → 退款 → 行退款记录 + 会员消息；**换货**：收货 → 出库扣减 → 发货 → 完成

- **消息**：下单/支付/退款/取消/发货/自提/售后/换货全覆盖，会员与访客分流（`MEMBER` / `CUSTOMER`）
- **评价/收藏/足迹**：均带归属校验
- **平台**：审计（异步单消费者写入 JaVers）、导出、风控、幂等、模块边界（ArchUnit）
