# 验收清单（按用户反馈逐条）

> 目的：让"我改完了"变成你自己能复现的检查。
> 分两类：**自动**（脚本一条命令）与**手工**（页面上点几下，给出期望结果）。
> 最近一次自动验收结果见本文件末尾。

## 一、一键自动验收

\`\`\`bash
# 需要 API 已启动（默认 41280）
bash scripts/dev-stack.sh start     # 首次或容器停了
node scripts/acceptance-check.mjs    # 或 make acceptance
\`\`\`

覆盖 8 项（全部为只读或幂等操作）：AI 状态端点、审计事件中文标签、枚举字典、
币种小数位、通知列表只含员工通知、全部已读幂等、市场启停端点、存储已配置时上传成功。
