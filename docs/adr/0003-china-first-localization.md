# ADR-0003: 中国市场优先与本地化策略

- 状态：Accepted
- 日期：2026-10-18

## 背景

项目定位跨境商城，但首阶段需要先打通国内完整交易闭环，再扩展香港、澳门、台湾地区。过早投入欧美税务、支付和合规会分散交付能力。

## 决策

- Phase 1–5 以中国大陆为主：zh-CN、CNY、微信支付/支付宝/银联（默认 Mock）、增值税发票、国内快递。
- Phase 6 扩展香港、澳门、台湾地区：zh-HK/zh-TW、HKD/MOP/TWD、当地支付/物流/自提、本地化仓、报关/税费、当地法律文档。
- 从第一天保留市场（Market）、locale、币种、法律主体、仓库-市场映射。
- 商品、类目、属性、法律文档使用独立翻译表，不在业务表里堆多语言字段。
- 法律文档必须人工审校；简繁转换不能替代法律翻译。

## 后果

- MVP 范围更聚焦，支付/物流/合规成本更低。
- 市场抽象必须从 Phase 0 就正确，否则港澳台扩展会返工。
- 英文和其他市场后置，但代码不写死中文。

## 替代方案

- 欧盟优先：税、支付、GDPR 成本高，不适合当前阶段。
